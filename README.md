# AWAKEN

Сайт демонструє концепцію сучасного ігрового комп'ютерного клубу AWAKEN. Тут представлено інформацію про зони для гри, тарифні плани, акції та форму бронювання місць. Проект створено як навчальний макет з ефектною анімацією, стильним оформленням і адаптивним інтерфейсом для користувачів.
